Introducción

¿Qué es VotaFacil?

Sistema de votación electrónica en JavaFX: el administrador gestiona el proceso y los electores emiten su voto de forma secreta.

🗄️Sin base de datos

Todo se guarda en archivos de texto dentro de datos/.

👥Dos roles

Administrador (gestiona) y Electores (votan).

Flujo del sistema

Login→ Gestión (CRUD)→ Apertura votación→ Voto secreto→ Escrutinio→ Exportar CSV

Modelo · Elector

Clase Elector

class Elector {
  private String codigo, cedula, nombre, contrasena;
  private boolean yaVoto;  // se guarda en archivo
  private boolean habilitado;  // SOLO en memoria
}
🗳️yaVoto

Controla si el elector ya emitió su voto (no puede repetir).

🛡️habilitado

Solo vive en memoria: habilita/deshabilita el acceso al sistema.

🙈Contraseña oculta

En tablas se muestra con asteriscos: getContrasenaOculta()

🎯Códigos reales

Electores E001..E010 cargados de ejemplo.
